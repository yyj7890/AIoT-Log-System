- 将群晖远程项目原地升级到 `v1.1.7-remote-mqtt`，保留所有旧标签且不更新局域网语义的 `latest`
- 在只有一个远程订阅后端实例的群晖环境重新实测，复核顶部离线/恢复状态、跨窗口 `PENDING`/`RESOLVED`/`PENDING`、QoS 1 重投、相邻去重、汇总内容和 MQTT 处理计数
- 在 Container Manager 留存停止、启动和恢复为 `healthy` 的状态变化证据；恢复过程中继续复用原 MySQL 数据卷和私有配置

## P1 安全（暂存跳过）

状态（2026-07-20）：全局 MQTT 凭证管理和关闭匿名访问已完成实机验收。管理网页登录、HTTP 设备认证、角色权限、每设备 MQTT 凭证和公网安全能力按用户当前安排暂停，不进入当前执行路线。暂停期间系统只能用于可信网络，不得开放公网；在线演示同步暂停。

- Spring Security + JWT 登录
- 管理员、运维、只读角色
- HTTP 设备身份认证
- 每设备独立 MQTT 用户名、密码和最小权限 ACL
- 公网部署启用 TLS，禁止匿名 MQTT

学习目标：掌握 Spring Security、JWT、密码哈希、设备凭证、MQTT ACL 和 TLS。

完成标准：未登录用户不能访问管理接口；不同角色权限生效；无效设备凭证不能上报；匿名 MQTT 被拒绝。
