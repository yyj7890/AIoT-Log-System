# AIoT 智能设备运行日志管理系统 - 第一阶段需求文档

## 1. 阶段目标

第一阶段目标是完成一个基础可用的设备运行日志管理系统。

系统应支持设备信息管理、设备运行日志记录、日志筛选、标签管理和首页统计。第一阶段重点是做出一个结构清晰、功能完整、可以运行和演示的版本。

第一阶段不实现复杂 AI 问答、RAG 知识库、网页归档、复杂工作流、大型实时大屏和多租户权限系统。

## 2. 用户角色

第一阶段暂定只有一个普通系统用户，不做复杂权限区分。

用户可以：

- 管理设备信息
- 记录设备日志
- 查看设备运行、异常、维护、巡检情况
- 通过筛选条件查找日志
- 查看首页统计数据

## 3. 功能模块

### 3.1 首页统计

首页用于快速了解设备整体运行情况。

需要展示：

- 设备总数
- 正常设备数
- 异常设备数
- 离线设备数
- 维护中设备数
- 待处理日志数
- 最近异常日志
- 最近维护记录

数据说明：

- 设备总数来自设备表总记录数。
- 异常设备数统计状态为异常的设备。
- 待处理日志数统计状态为待处理的日志。
- 最近异常日志按创建时间倒序展示最近若干条异常日志。
- 最近维护记录按创建时间倒序展示最近若干条维护日志。

### 3.2 设备管理

设备管理用于维护 AI 小智及其他 AIoT 设备的基础信息。

#### 3.2.1 设备列表

列表字段：

- 设备名称
- 设备编号
- 设备类型
- 安装位置
- 当前状态
- 创建时间
- 操作按钮

支持操作：

- 查看详情
- 编辑设备
- 删除设备
- 查看设备日志

支持筛选：

- 设备名称关键词
- 设备编号关键词
- 设备状态
- 设备类型

#### 3.2.2 新增设备

表单字段：

- 设备名称，必填
- 设备编号，必填，唯一
- 设备类型，必填
- 安装位置，非必填
- 当前状态，必填，默认正常
- 设备描述，非必填

校验规则：

- 设备名称不能为空。
- 设备编号不能为空。
- 设备编号不能重复。
- 当前状态必须从系统定义的状态中选择。

#### 3.2.3 编辑设备

允许修改：

- 设备名称
- 设备类型
- 安装位置
- 当前状态
- 设备描述

不建议修改：

- 设备编号

如果允许修改设备编号，也必须保证编号唯一。

#### 3.2.4 删除设备

删除设备时需要处理该设备下的日志。

第一阶段建议采用限制删除：

- 如果设备下存在日志，不允许删除。
- 如果设备下没有日志，允许删除。

这样可以避免误删日志数据，逻辑也更适合学生项目。

#### 3.2.5 设备详情

详情页展示：

- 设备基础信息
- 设备当前状态
- 该设备最近日志
- 该设备异常日志数量
- 该设备待处理日志数量

详情页支持：

- 给该设备新增日志
- 查看该设备全部日志

### 3.3 日志管理

日志管理用于记录设备运行、异常、维护和巡检情况。

#### 3.3.1 日志列表

列表字段：

- 日志标题
- 所属设备
- 日志类型
- 日志等级
- 处理状态
- 标签
- 创建时间
- 操作按钮

支持操作：

- 查看详情
- 编辑日志
- 删除日志
- 修改处理状态

支持筛选：

- 所属设备
- 日志类型
- 日志等级
- 处理状态
- 标签
- 关键词
- 开始时间
- 结束时间

关键词搜索范围：

- 日志标题
- 日志内容
- 设备名称
- 设备编号

#### 3.3.2 新增日志

表单字段：

- 所属设备，必填
- 日志标题，必填
- 日志内容，必填
- 日志类型，必填
- 日志等级，必填，默认普通
- 处理状态，必填，默认待处理
- 标签，非必填

校验规则：

- 所属设备不能为空。
- 日志标题不能为空。
- 日志内容不能为空。
- 日志类型必须从系统定义的类型中选择。
- 日志等级必须从系统定义的等级中选择。
- 处理状态必须从系统定义的状态中选择。

#### 3.3.3 编辑日志

允许修改：

- 日志标题
- 日志内容
- 日志类型
- 日志等级
- 处理状态
- 标签

所属设备可以允许修改，但第一阶段建议不作为主要操作。

#### 3.3.4 删除日志

删除日志时，应同时删除该日志与标签的关联关系。

#### 3.3.5 日志详情

详情页展示：

- 所属设备
- 日志标题
- 日志内容
- 日志类型
- 日志等级
- 处理状态
- 标签
- 创建时间
- 更新时间

### 3.4 标签管理

标签用于对日志进行分类，方便后续筛选。

第一阶段可以做成轻量功能：

- 新增标签
- 删除标签
- 日志创建或编辑时选择标签
- 日志列表按标签筛选

默认标签建议：

- 异常
- 维修
- 实验
- 告警
- 已解决
- 网络
- 语音模块
- 传感器

标签规则：

- 标签名称不能为空。
- 标签名称不能重复。
- 删除标签时，应同时删除日志和标签的关联关系。

## 4. 枚举定义

### 4.1 设备状态

| 编码 | 中文名称 | 说明 |
| --- | --- | --- |
| NORMAL | 正常 | 设备运行正常 |
| ABNORMAL | 异常 | 设备存在异常 |
| OFFLINE | 离线 | 设备当前不可用或未连接 |
| MAINTENANCE | 维护中 | 设备正在维护 |

### 4.2 日志类型

| 编码 | 中文名称 | 说明 |
| --- | --- | --- |
| RUNNING | 运行日志 | 记录设备正常运行信息 |
| ERROR | 异常日志 | 记录设备异常问题 |
| MAINTENANCE | 维护日志 | 记录维修、保养、更换模块等操作 |
| INSPECTION | 巡检日志 | 记录人工检查设备情况 |

### 4.3 日志等级

| 编码 | 中文名称 | 说明 |
| --- | --- | --- |
| INFO | 普通 | 一般运行记录 |
| WARNING | 警告 | 需要关注但不一定严重 |
| ERROR | 严重 | 明确异常或影响设备使用 |

### 4.4 日志处理状态

| 编码 | 中文名称 | 说明 |
| --- | --- | --- |
| PENDING | 待处理 | 问题尚未处理 |
| PROCESSING | 处理中 | 问题正在处理 |
| RESOLVED | 已解决 | 问题已经解决 |

## 5. 页面结构

第一阶段建议包含以下页面：

- 首页仪表盘
- 设备列表页
- 设备详情页
- 新增设备页或弹窗
- 编辑设备页或弹窗
- 日志列表页
- 日志详情页
- 新增日志页或弹窗
- 编辑日志页或弹窗
- 标签管理页或标签管理弹窗

推荐优先级：

1. 首页仪表盘
2. 设备列表
3. 设备新增和编辑
4. 设备详情
5. 日志列表
6. 日志新增和编辑
7. 日志筛选
8. 标签管理

## 6. 典型业务流程

### 6.1 添加设备

1. 用户进入设备列表页。
2. 点击新增设备。
3. 填写设备名称、设备编号、设备类型、安装位置和状态。
4. 提交表单。
5. 系统保存设备信息。
6. 设备列表展示新设备。

### 6.2 给设备添加异常日志

1. 用户进入设备详情页。
2. 点击新增日志。
3. 选择日志类型为异常日志。
4. 填写异常标题和异常内容。
5. 选择日志等级和处理状态。
6. 选择相关标签，例如异常、告警、语音模块。
7. 提交表单。
8. 系统保存日志，并在设备详情和日志列表中展示。

### 6.3 处理异常日志

1. 用户进入日志列表。
2. 筛选待处理异常日志。
3. 打开日志详情。
4. 根据处理进度将状态改为处理中或已解决。
5. 系统更新日志状态。

### 6.4 查看首页统计

1. 用户进入首页。
2. 系统展示设备总数、异常设备数、待处理日志数。
3. 用户查看最近异常日志和最近维护记录。
4. 用户可以点击记录进入日志详情。

## 7. 第一阶段验收标准

第一阶段完成后，应满足以下标准：

- 可以新增、编辑、删除、查看设备。
- 可以查看设备列表和设备详情。
- 可以给指定设备新增日志。
- 可以查看全部日志。
- 可以查看某台设备的全部日志。
- 可以编辑、删除日志。
- 可以使用日志类型、状态、等级、设备、关键词、时间范围进行筛选。
- 可以给日志添加标签。
- 可以按标签筛选日志。
- 首页可以展示基础统计数据。
- 页面功能完整，能完成一次完整演示流程。

## 8. 演示数据建议

建议至少准备 3 台设备：

- AI 小智语音助手
- 实验室温湿度采集节点
- 教室环境监测终端

建议至少准备 8 条日志：

- 运行日志：设备启动成功，WiFi 连接成功。
- 异常日志：语音唤醒失败，多次无法响应唤醒词。
- 维护日志：更换麦克风模块后恢复正常。
- 巡检日志：检查电源、网络和传感器状态，运行正常。
- 异常日志：设备短暂离线。
- 运行日志：温湿度采集正常。
- 维护日志：清理设备外壳和接口。
- 巡检日志：检查设备安装位置和供电状态。

## 9. 后续阶段预留

第一阶段设计时应为第二、第三阶段保留扩展空间：

- 设备表可以后续增加通信协议、IP 地址、最后在线时间。
- 日志表可以后续增加来源字段，用于区分手动录入和设备自动上报。
- 后续可以增加传感器数据表。
- 后续可以增加 AI 分析结果表。
- 后续可以接入 HTTP 或 MQTT 上报接口。
