# 项目截图准备清单

本目录用于保存可公开展示、已经脱敏的 GitHub 项目截图。提交前请先执行根目录的 [安全检查清单](../SECURITY-CHECKLIST.md)。不要提交原始截屏、浏览器导出文件或包含真实设备数据的图片。

| 建议文件名 | 页面与内容 | 展示用途 | 必须脱敏 |
| --- | --- | --- | --- |
| `01-dashboard.png` | 首页统计卡片、设备状态、最近异常或维护概览 | 展示系统总览与可视化能力 | 真实设备名称、设备编码、MAC、局域网 IP、时间线中的个人信息 |
| `02-device-xiaozhi-001.png` | `XIAOZHI-001` 设备详情、最近上报和趋势 | 证明真实小智设备已接入 | MAC、IP、SSID、精确地理位置、真实传感器数据；可使用演示数据或局部打码 |
| `03-runtime-logs-zh.png` | 中文化运行日志与启动事件汇总 | 展示日志可读性与 `/log` 接入 | 原始运行日志、精确时间、IP、Wi-Fi 名称、设备唯一标识和任何 Token |
| `04-mqtt-auth-status.png` | MQTT 状态页的认证已启用状态 | 展示已关闭匿名访问和认证能力 | **完整遮挡**用户名、密码、Token、Broker 地址、IP 和可能暴露凭证的浏览器自动填充内容 |
| `05-batch-delete-mode.png` | 日志页面的批量删除模式、勾选和二次确认 | 展示批量维护交互 | 日志正文、设备编号、操作者信息；确认弹窗中不可显示真实数据 |

## 截图原则

- 建议分辨率至少为 1440×900，使用统一浏览器缩放比例；保留页面导航和主要标题，方便读者理解页面位置。
- 截图只呈现必要的界面，不打开开发者工具、终端、配置文件、地址栏查询参数或密码管理器。
- 真实 MAC、局域网 IP、SSID、用户标识、MQTT 凭证、Token、完整运行日志和数据库数据均不得出现。必要时使用演示数据、马赛克或重新截取。
- 原始图片请放在 `screenshots/raw/` 或 `screenshots/private/`（已被 Git 忽略）；只有检查合格的导出图片才可放入本目录。
- 每次新增图片后，在根目录 `README.md` 的“项目截图”小节添加图片链接和一句说明。
